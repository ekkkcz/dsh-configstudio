# ConfigStudio 使用指南

[返回项目首页](../README.md)

## 安装与排查

需要 Node.js ≥ 22.5（使用内置 `node:sqlite`）、DSH 和至少一个可调用的模型服务。当前已验证 Windows 11 + Chromium、DSH `0.1.6-alpha.2`，其他环境尚未验证。

从[仓库](https://github.com/ekkkcz/dsh-configstudio)克隆源码，或选择 **Code → Download ZIP** 后解压。插件无需构建，安装时指向源码目录。

### 已有 Web profile

在源码目录中运行以下 PowerShell 命令，将 `web` 替换为自己的 profile 名：

```powershell
dsh plugin --profile web add (Get-Location).Path
```

安装后重启对应 profile 的 DSH，在 Web 侧栏打开「配置对比」。

### 新建测试 profile

先从默认 Web 配置创建 profile，再安装插件：

```powershell
dsh --profile configstudio-test --from-default-profile web
```

完成初始化后，停止该实例，再在源码目录中执行：

```powershell
dsh plugin --profile configstudio-test add (Get-Location).Path
dsh --profile configstudio-test web
```

不要对尚不存在的 profile 直接执行 `plugin add`：在已验证的 DSH 版本中，这会创建缺少 Web 界面的基础配置。相关原因见 [DSH 接入记录](dsh-integration.md)。

若侧栏没有入口，先确认重启过 DSH，再检查配置中是否同时包含插件和 Web 应用：

```powershell
dsh --profile configstudio-test --dump-config | Select-String 'configstudio|web-app'
```

模型服务应在 DSH 的 `/models` 中可见且能实际调用。也可以检查目录接口：

```powershell
curl http://127.0.0.1:<你的DSH端口>/configstudio/api/models
```

查看 `providers` 是否非空、`errors` 是否为空。只有一个模型也能使用：为不同候选设置不同提示词或参数即可。

### 可选截图依赖

初始截图需要 Playwright 和 Chromium。插件会尝试从 DSH checkout 或全局 npm 目录发现 Playwright；缺少依赖时标注「未检查」，生成与预览仍可使用。

```powershell
npm i -g playwright
npx playwright install chromium
```

也可通过环境变量 `HTML_ARENA_PLAYWRIGHT_ANCHOR` 指定含 Playwright 的目录。该变量保留历史名称。

### 卸载与升级

```powershell
dsh plugin --profile <profile> remove '@dsh-external/configstudio'
```

卸载不删除 `$DSH_HOME/configstudio` 中的实验记录。升级前建议备份数据；数据结构迁移是单向的，旧版插件会拒绝打开比自身支持版本更新的数据目录。复测包格式版本过新时也会拒绝导入。

## 配置与对照

一次「实验」包含一道题、2–4 个候选、生成结果和评价。每个「候选」代表一套配置，一次运行称为一次「尝试」。重试或追加轮次会新增尝试，保留旧记录。

每个候选可独立选择 provider / model，并设置系统提示词、提示词片段、温度、输出上限与思考档位：

| 对照方式 | 示例 |
| --- | --- |
| 同模型，不同配置 | 只改变提示词或思考档位，观察结果变化 |
| 不同模型，相同设置 | 在各模型支持的范围内保持其他设置一致 |
| 自由组合 | 为各候选搭配不同模型和参数，比较整套方案 |

想观察某一项设置的影响，可以先固定其他变量。单次生成存在随机性，可追加轮次观察结果是否一致。

不同模型对参数的支持并不相同。思考档位按可用能力提供选项；当前 DSH 接口不能完整表达温度支持情况，输出上限的默认值也不代表模型的实际最大容量。上游可能拒绝或限制参数，详见[验收记录](acceptance.md)。

### 生成与预览

每个候选每轮发起一次模型调用，不开启工具循环、不自动修复或重试。题目或起始 HTML 超限时明确拒绝，不静默截断；返回多个 HTML 块时，由你选择展示哪一个。

作品使用相同逻辑视口，每行两个。可切换手机 / 桌面尺寸、缩小看全、1:1 横向展开、同步滚动、重置或放大单个作品。离开对比页会回收预览资源，返回时重新加载，作品内的临时操作状态会丢失。

预览默认离线，外部请求由 CSP 阻止；受控 CDN 模式仅放行白名单域名。两种模式均不改写作品代码。

### 盲选与评价

点击「隐藏配置身份」后，模型、配方名与用量速度信息一并隐藏。体验作品后记录偏好、平局或无法判断，再揭晓配置。作品内容本身可能暴露模型身份，因此不保证严格双盲；已揭晓的实验不能恢复为未揭晓状态。

历史支持按标题、类型与评价状态筛选，也可以复制实验继续尝试。

### 用量、速度与费用

插件免费，模型调用按服务商规则计费。调用次数通常为候选数 × 轮数；手动重跑会产生新的调用。取消或超时会尽力中止请求，已产生的用量仍可能计费。

作品卡展示输入、输出、推理 token 数、首正文延迟和总耗时。未上报的字段显示「未上报」。总速度按 `输出 tokens ÷ 总耗时` 计算，包含等待与推理阶段，不等同于正文流式输出速度。

## 配方、分享与数据

「配方」是一套可复用的调用配置。修改会追加新版本；实验保存启动时的配置快照，后续修改不回写历史。

| 导出类型 | 内容与用途 |
| --- | --- |
| 展示包 | 报告、作品、初始截图与公开元数据。解压后打开 `index.html` 查看，无需安装插件 |
| 复测包 | 题目、配方、预览与输出规则及版本信息，不含生成结果。对方导入后使用自己的 DSH 模型服务重跑 |

导入时先检查包内容、文件校验值、格式版本与模型可用性；缺少模型时需重新选择，不自动替换或发起调用。展示包与复测包均由用户自行分享，没有自动上传、托管或公共投票服务。

实验、原始输出与作品保存在本机 `$DSH_HOME/configstudio`，同一用户的不同 profile 共享这份数据。插件调用 DSH 管理的模型服务，凭据由 DSH 适配器解析，不作为插件实验数据保存。

导出时仅脱敏插件生成的元数据；题目、配方和作品内容原样保留，可能含路径或密钥的文本会提示检查。展示包不包含推理全文和凭据，原始输出正文需手动勾选；复测包不包含作品结果或原始输出正文。

## 常见问题

**生成很久没有正文？** 推理模型可能先处理推理内容，再返回正文。新建对比或对比页可设置运行上限；自动模式会随思考档位调整。超时后可修改上限并重跑该候选，原有结果与评价会保留。

**运行上限足够，仍然超时？** 上游或 DSH 适配器可能另有流空闲超时限制。插件的运行上限不能覆盖这些限制，具体报错与历史案例见[更新记录](../CHANGELOG.md)。

**作品空白或不完整？** 可能是输出被截断、生成代码有错误，或预览策略阻止了外部依赖。先查看「展开配置 → 提取告警」与原始输出，再按模型支持情况调整输出上限、简化题目或重跑。当前截断告警尚未直接显示在作品卡上。

**为什么没有截图？** 先检查 Playwright / Chromium 是否可用。当前仅支持初始状态截图，不支持交互后的状态捕获；缺少截图不代表生成失败。

## 当前范围与验证情况

- 当前产物类型为单文件 HTML，输入为文字题目与可选起始 HTML。
- 尚不支持参考图、批量多次采样、真实 Skill / 工具使用对照、交互后截图。
- 展示包离线打开验证使用同一台机器的另一个目录，并未覆盖独立设备。
- 功能验收与已知缺口见[验收记录](acceptance.md)，历史开发过程见[进度记录](progress.md)，最新变更见[更新记录](../CHANGELOG.md)。
